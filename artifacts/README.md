# Runtime verification artifacts

ملفات `artifacts/` ناتجة عن تشغيلات محلية ومحددة ببيئة ونسخة كود بعينها؛ لذلك تُستبعد افتراضيًا من Git، بما فيها `*_verification_receipt.json`.

لا يُعامل أي إيصال محلي قديم بوصفه دليلًا على حالة الفرع الحالي. الدليل القابل لإعادة الإنتاج هو نتيجة GitHub Actions والأوامر الموثقة في `README.md`. إذا تقرر نشر إيصال بعينه، فيجب مراجعته وتحديث Hashes والحدود ثم إضافته صراحةً بتغيير مقصود في `.gitignore`.
