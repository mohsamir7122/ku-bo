# Logs

Only bounded, sanitized summaries are committed. Credentials, tokens, private
Drive identifiers, raw conversations, private source locators, licensed bytes,
and large raw command output must remain outside Git.

The baseline, failed intermediate gates, latest 2,307-test pass, deterministic
Stage 1/2 dry-run digests, and package smoke results are recorded in
`../validation-report.md` and `../run-manifest.json`.
